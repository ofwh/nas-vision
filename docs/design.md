# UI 开发规范

- 优先复用已有 UI、窗口和插件框架；组件安装与样式定制遵守 [AGENTS.md](../AGENTS.md#ui-组件)。
- 弹窗模式、头部、窗口控制和内容布局遵守[弹窗技能](skills/nas-vision-modals/SKILL.md)。
- 插件目录、注册、配置、导航和数据交互遵守[插件技能](skills/nas-vision-plugins/SKILL.md)。
- 页面布局与交互遵守通用组件规范，页面特有约束以对应实现为准。
- 通用规范不包含具体页面的尺寸常量、业务数据或实现代码。

## 反馈与确认

- 复用应用已挂载的反馈组件，业务侧不重复挂载或覆盖通用外观；样式定制遵守 [UI 组件规范](../AGENTS.md#ui-组件)。
- 提示文案使用所属模块的多语言资源，异常信息转换为用户可理解的内容后展示。

### Toast

- 无需用户确认的操作反馈与校验提示使用 Toast，业务侧统一通过 [useToast](../hooks/useToast.ts) 调用，不直接导入 UI 库的 manager。
- 提示状态与反馈语义一致；同一异步操作的持续反馈更新原提示，避免重复创建。

### MessageBox

- 操作确认、需要用户关闭的提示及单值输入统一通过 [useMessageBox](../hooks/useMessageBox.ts) 调用，不使用浏览器原生消息框或重复实现同类弹窗。
- 依赖用户决定的操作须等待弹窗结果；取消时终止后续操作，输入提交不得通过字符串真假值判断。
- 必填约束由组件统一处理；自定义内容通过内容插槽组合，业务侧负责其数据和额外校验，不改变公共弹窗结构。
