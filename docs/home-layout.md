# 首页布局

首页使用固定尺寸的蜂巢视图，由两侧弹性留白与中间内容区组成。

## 页面

| 区域            | 尺寸与位置                               |
| --------------- | ---------------------------------------- |
| 中间内容区      | 宽 1200px，纵向排列 header、main、footer |
| header / footer | 最小高 24px，分配剩余高度                |
| main            | 1200 × 624px，内容居中                   |
| 两侧留白        | 等分剩余宽度，最小宽 124px               |
| 左侧菜单        | 宽 68px，纵向居中                        |

页面最大宽度为 1600px。布局入口位于 `app/(home)/page.tsx` 与 `app/(home)/layout.tsx`，视图组件位于 `components/home/`。

## 蜂巢视图

每页 13 个位置，分三行并水平居中：

| 行  | 尺寸         | 项数 |
| --- | ------------ | ---- |
| 上  | 960 × 208px  | 4    |
| 中  | 1200 × 208px | 5    |
| 下  | 960 × 208px  | 4    |

应用按从上到下、从左到右的顺序填充，空位置保留占位，超过 13 个时分页。

每项尺寸为 240 × 208px，两侧各留 20px，内容从顶部下移 26px。图标为 128 × 128px 圆形，文案区域宽 200px、高 22px，与图标间距 10px。

对应实现：`components/home/AppList.tsx`、`AppPage.tsx`、`AppItem.tsx`；菜单为 `Sidebar.tsx`。
